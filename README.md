# Heróis da Tecnologia

Guias ilustrados de videochamadas e segurança digital para pessoas idosas.

Site estático em HTML, CSS e JavaScript. Inclui português e inglês, leitura de instruções e progresso guardado no navegador.

## Execução
Sirva a pasta raiz com um servidor HTTP estático. O GitHub Pages publica a branch main na raiz.
